Transformers Architecture in NLP

What are Transformers?

Transformers are deep learning models designed for handling sequential data, particularly in natural language processing (NLP). Introduced in the paper "Attention is All You Need" (2017), they use self-attention mechanisms to model relationships between words, regardless of their position in the sequence.

1. Encoder

The encoder takes an input sequence (e.g., a sentence) and converts it into a contextual representation (embeddings) using stacked self-attention and feed-forward layers.
Example Models: BERT, RoBERTa (good for understanding text).

2. Decoder

The decoder takes encoded representations and generates output sequences one token at a time. It uses masked self-attention to ensure prediction happens in sequence.
Example Models: GPT, GPT-2, GPT-4 (good for generating text).

3. Encoder-Decoder

Combines both components. The encoder processes the input, and the decoder generates the output based on encoder outputs and previously generated tokens.
Example Models: T5, BART (used for translation, summarization, Q&A).

Key Features
  • Uses self-attention instead of recurrence (RNNs/LSTMs)
  • Enables parallel training for efficiency
  • Captures long-range dependencies in text
  • Foundation of most modern NLP models
